# Diretrizes de Ícones e Estética Visual

- **Sempre usar ícones vetoriais em SVG moderno** (inline SVG limpo com `stroke="currentColor"`, `stroke-width="2"`, etc.) em botões, abas, badges, cards, seletores e itens de navegação.
- **Evitar o uso de emojis nativos** (ex.: 🚀, 🔒, 📊, 📋, 👥, 🎂, 🏛️, 👁️, ✍️, etc.) na interface do usuário, preferindo iconografia SVG estilizada com cores harmoniosas e fundo sutil quando aplicável.
- Assegurar dimensões consistentes (ex.: 14x14px para botões compactos, 16x16px ou 18x18px para cards, 20-24px para alertas).
